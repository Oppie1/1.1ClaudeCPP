## Code Comments and Documentation

### Educational Comments for Learners
- Comments should explain the **purpose** and **reasoning** behind code, not just state what the code does
- Use clear, accessible language appropriate for the target audience
- Balance detail: provide enough context to teach, but avoid verbosity that obscures the code
- For student-facing code, explain concepts as they relate to the broader programming principles
- Highlight common pitfalls and key points that reinforce learning objectives
